Apa itu Pseudo-class? Di CSS, :hover adalah pseudo-class selector (ditulis dengan satu titik dua :). Ia aktif secara dinamis saat kursor pengguna berada di atas elemen, tanpa perlu mengubah HTML atau menulis JavaScript!
CSS Terapan (Realtime Update)
/* 1. Kondisi Awal: Wajib pasang transition di sini agar animasi pulang-pergi halus */
.card {
  cursor: pointer;
  border: 1px solid #e2e8f0;
  transition: transform 0.25s ease,
              box-shadow 0.25s ease,
              border-color 0.25s ease;
}

/* 2. Pseudo-class :hover (Aktif seketika saat pointer mouse melayang di atas .card) */
.card:hover {
  transform: translateY(-4px) scale(1.03);
  border-color: rgba(249, 115, 22, 0.4);
  box-shadow: 0 10px 24px rgba(249, 115, 22, 0.18), 0 0 14px rgba(251, 146, 60, 0.28);
}
Kamus Istilah: Pseudo-class vs Pseudo-element
• Pseudo-class (Satu titik dua :): Memilih elemen berdasarkan status interaksi atau kondisi sementara.
  Contoh: :hover (melayang), :focus (saat diklik form), :active (saat dipencet), :nth-child().

• Pseudo-element (Dua titik dua ::): Membuat atau memilih bagian sub-elemen tiruan di dalam elemen.
  Contoh: ::before (konten sisipan awal), ::after (konten sisipan akhir), ::placeholder.

• Transform vs Transition:
  - transform adalah bentuk perubahannya (geser, putar, perbesar).
  - transition adalah jembatan waktunya (durasi & keluwesan gerakan dari titik A ke titik B).
